# 🏨 Real Dashboard

A modern hotel management dashboard built with **React**, **TypeScript**, **TanStack Query**, **Axios**, and **MSW**. The application demonstrates a production-style frontend architecture with authentication, CRUD operations, dashboards, charts, and persistent UI state.

## 🌐 Live Demo

**Application:** https://real-dashboard-nu.vercel.app/login

## 📂 Repository

**GitHub:** https://github.com/enesaygur/real-dashboard

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/enesaygur/real-dashboard.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
